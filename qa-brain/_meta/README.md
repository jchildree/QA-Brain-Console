# QA Second Brain — Vault Guide

## Architecture

```
┌─────────────────────────────────────────┐
│  AI / Copilot Layer                     │  ← Chat, RAG, reasoning
├─────────────────────────────────────────┤
│  Knowledge Model Layer                  │  ← Metadata, schemas, links
├─────────────────────────────────────────┤
│  Storage Layer (Markdown)               │  ← Version-controlled source
├─────────────────────────────────────────┤
│  Automation Layer                       │  ← Templates, QuickAdd, Git
└─────────────────────────────────────────┘
```

## Folder map

| Folder | Purpose |
|--------|---------|
| `_templates/` | Templater-powered controlled forms |
| `_dashboards/` | Dataview query boards |
| `_meta/` | Vault documentation and setup guides |
| `SOP/` | Controlled procedures |
| `INCIDENT/` | Deviations and nonconformances |
| `CAP/` | Corrective + preventive action plans |
| `CHANGE/` | Change requests |
| `AUDIT/` | Audit reports and findings |
| `TRAINING/` | Training records |

## ID convention

All document IDs follow `{TYPE}-{YYYYMMDD}-{seq}` pattern, auto-generated by Templater.

| Type | Example ID |
|------|-----------|
| SOP | SOP-20260528-001 |
| Incident | INC-20260528-001 |
| CAP | CAP-20260528-001 |
| Change | CHG-20260528-001 |
| Audit | AUD-20260528-001 |
| Training | TRN-20260528-001 |

## Relationship model

```
SOP ←── INCIDENT ──→ CAP
              ↑          ↓
           AUDIT    Root Cause
              ↑
           TRAINING
```

## Status lifecycle

```
Draft → In Review → Approved → Obsolete
```

## Personal layer principle

This vault is your *thinking and analysis tool*, not a replacement for Intellect.
- Draft here, finalize there
- Use Copilot for root cause analysis and trend detection
- Use Dataview for audit prep and compliance views
- Push approved records to Intellect as the system of record
