# QA-Brain Vault

Parent source. Ingested from `raw/qa-brain/` (snapshot copy of `qa-brain/` for wiki purposes only -- not authoritative, live vault untouched).

An Obsidian-based personal QMS drafting/analysis layer for an analytical laboratory (QA, Chemists, Analysts). Not the system of record -- approved records get pushed to Intellect (EQMS). Structure: 6 record-type folders (SOP/INCIDENT/CAP/CHANGE/AUDIT/TRAINING) + `_templates/` (Templater schemas) + `_dashboards/` (Dataview boards) + `_meta/` (setup docs).
