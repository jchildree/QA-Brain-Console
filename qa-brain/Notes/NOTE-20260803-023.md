# Dataview Path Prefix Mismatch

All `_dashboards/` queries use `FROM "docs/qa-brain/<Folder>"`. Per CLAUDE.md this is a known discrepancy -- the vault's actual mount point must be checked before editing queries, since the bare folder path (`qa-brain/SOP` etc, no `docs/` prefix) is what's used elsewhere in the repo. If the vault isn't actually mounted under a `docs/` prefix in Obsidian, every dashboard query returns empty.
