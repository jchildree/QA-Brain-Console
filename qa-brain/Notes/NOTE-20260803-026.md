# Personal Layer vs System of Record

Vault is a drafting/analysis layer, not the QMS system of record. Real system is Intellect (EQMS). Workflow: draft here -> finalize/push approved records to Intellect. Copilot used for root-cause analysis and trend detection here; Dataview used for audit prep and compliance views here. Nothing in this vault should be treated as final/authoritative documentation of the live QMS.
