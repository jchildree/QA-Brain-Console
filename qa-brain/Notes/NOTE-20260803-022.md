# Dashboard Rebuild Direction

Decision record. Confirmed 2026-07-15, resolves the 5 open questions in [[Dashboard Feature Gap Map]]. Formalized as `ADR-001-dashboard-rebuild-direction.md` (see `docs/Obsidian Vault/QA-Brain-Project/INDEX.md`).

## Confirmed

1. Salvage usable patterns from all 3 tsx prototypes -- adapt code/text as needed, even heavily, rather than requiring a clean domain match.
2. [[Gemini Multimodal Workspace Compiler]]'s asset-ingestion model (Photos/Videos/Docs/Keep) is not domain-irrelevant after all -- QA-Brain will ingest sample photos, PowerPoint decks, and other file types as record attachments/evidence. The asset-toggle intake pattern generalizes.
3. [[EQMS Engine Registry Sandbox]] is the closest of the 3 to an actual dashboard -- primary structural base (5-tab console, status-lifecycle cards, schema-as-data blueprints).
4. [[Gemini Multimodal Workspace Compiler]] is the starting point/example for the build -- repoint asset ingestion at QA documents/intent instead of Google Photos/Video/Keep, and replace the Gemini API call with Claude.
5. Direction: dynamic form-builder (schema-as-data blueprint pattern from Engine Registry Sandbox) driving a nicer dashboard that updates/replaces the current [[QA-Brain - Dashboards]] Dataview tables.

## Resolved 2026-07-15

- **App location**: new top-level `app/`, sibling to `qa-brain/` and `docs/`.
- **Persistence**: reads/writes the real `qa-brain/*.md` frontmatter directly -- no separate DB, frontmatter stays the source of truth.
- **Claude integration**: backend proxy holds the API key -- browser never sees it (avoids the client-key anti-pattern flagged in [[EQMS Cognitive Compiler Dashboard]]).
- **First-pass scope**: vertical slice on **SOP** first (simplest schema, only type with auto review-cadence -- lowest-risk starting point) -- dynamic form + status dashboard + Claude-assisted intake for SOP only, before scaling to the other 5 record types.
- **Asset handling**: extract + attach -- Claude extracts relevant text/findings from uploaded files (OCR photos, summarize slides/docs) to help draft frontmatter/body, and the source file stays attached as evidence on the record.
