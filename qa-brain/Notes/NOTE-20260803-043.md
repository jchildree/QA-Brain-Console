# QA-Brain - Dashboards

Sub-source of [[QA-Brain Vault]]. Folder `_dashboards/` -- 5 Dataview markdown boards + 1 canvas.

- `Home.md` -- "QA Mission Control": open CAPs, open incidents, SOPs pending review (<=30 days), recent changes (last 10), incomplete training, upcoming audits. Links out to the other 4 boards + `EQMS-Project-Board.canvas`.
- `CAP-Tracker.md` -- open CAPs, effectiveness checks due (<=14 days), CAP->Incident traceability, recurring root causes (grouped), Copilot prompt snippets.
- `SOP-Control.md` -- all controlled SOPs, overdue-for-review, in draft/review, obsolete, SOP->Incident linkage.
- `Audit-Prep.md` -- open audit findings, findings->CAP traceability, documents updated last 30 days, recently approved (last 90 days), training compliance.
- `Incident-Trends.md` -- open incidents, by root cause (grouped/sorted by count), by department (grouped), incidents without a linked CAP, closed this month.
- `EQMS-Project-Board.canvas` -- not read (binary/canvas format, out of scope for this text ingest).

All queries use `FROM "docs/qa-brain/<Folder>"` -- see [[Dataview Path Prefix Mismatch]] for a live discrepancy this creates.
