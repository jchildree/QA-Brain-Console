# Business Identifier Numbering Stale Page

The current page reads:

```
| Quality Event | `QE-YYYYMMDD-NNNN` | `QE-20260602-0003` |
| CAP           | `CAP-YYYYMMDD-NNNN` | `CAP-20260602-0001` |
| Document      | `DOC-YYYYMMDD-NNNN` or template | `DOC-20260602-0001` |
```

with CAP counted all-time and Document numbers built from a
`document_type.numbering_template` with `{SEQ}`/`{DATE}` substitution.

ADR-032 (ACCEPTED 2026-06-10) replaced all three formats with
`QE-{SLUG}-{YYYY}-{NNNNN}`, a year-scoped `CAP-{YYYY}-{NNNNN}`, and
`IL-{DEPT}-{TYPE}-{NNN}` for documents, and explicitly removed the
`numbering_template` override mechanism. A suggestion note filed the same
day the ADR was accepted --
`_suggestions/2026-06-10_business-identifier-numbering-update.md` -- spells
out this exact diff and is still sitting in the unarchived suggestion
queue 26 days later (as of 2026-07-06), while comparable suggestions from
2026-06-02 and 2026-06-09 are already filed under
`_suggestions/archive/APPROVED_*`. The suggestion was correct and never
applied.
