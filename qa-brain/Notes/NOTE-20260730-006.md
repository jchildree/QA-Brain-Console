# Docs Owed, Never Written

`apps/eqms/CLAUDE.md` carries a "Docs owed (Nexus rule -- not yet
written)" section listing:

- `docs/admin/eqms-admin-guide.md`
- `docs/troubleshooting/eqms-troubleshooting.md`
- an update to `docs/setup/production-deployment.md`

None of these paths resolve, checked both as app-scoped
(`apps/eqms/docs/admin/...`) and as the shared root-level location the
root `CLAUDE.md` "Documentation required" rule implies (`nexus/docs/admin/...`).
In fact no root-level `nexus/docs/` directory exists at all -- the shared
convention every app is supposed to write into has never been
instantiated, so EQMS is not an outlier here, it's just the app whose own
`CLAUDE.md` says so out loud.
