# EQMS Cognitive Compiler Dashboard

Source: `raw/eqms_cognitive_compiler_dashboard.tsx` (969 lines). Standalone React/Tailwind prototype, no build system, no backend.

Not a records dashboard -- it's a free-text-to-structured-record compiler. User pastes a raw lab observation, picks a matrix (Metals/Animals/Water), and the app runs a simulated lexer->AST->typecheck->codegen pipeline that extracts metadata, generates a fake SHA-256, T-SQL INSERT DDL, and a message-outbox event. Optional live Gemini API call (client-side plaintext key, security anti-pattern); falls back to a hardcoded offline heuristic extractor when no key given. Renders a custom Canvas force-directed "thought cloud" graph (no charting library) of extracted tokens, plus tabs for AST JSON, generated SQL, and outbox log.

## Feature map (see [[Dashboard Feature Gap Map]] for cross-file synthesis)

Applicable: free-text-to-frontmatter extraction pattern (biggest fit -- could drive an "LLM-assisted new INCIDENT/CAP draft" flow), required-field validation warnings, matrix-style segmented control as a record-type picker, relationship-graph rendering repointed at real `related_documents` links.

Not applicable: T-SQL/SQL Server DDL generation (no DB in this vault), transactional outbox/message queue (no microservice backend), fake SHA-256 "integrity signature" (cosmetic, would give false audit-trail assurance if reused), client-side plaintext API key field, physics thought-cloud (no query/status/date semantics -- doesn't answer "what's open/overdue").
