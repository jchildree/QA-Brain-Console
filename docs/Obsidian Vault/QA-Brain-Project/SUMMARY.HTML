ADR-001 Dashboard Rebuild Direction ACCEPTED Frontend · Backend · Data 2026-07-15

ADR-001 at a glance

Decision: build a new dashboard app under app/, reading/writing qa-brain/*.md frontmatter directly, salvaging UI/architecture patterns (not domain content) from 3 standalone React prototypes that were sitting unused at the repo root.

App location
app/, sibling to qa-brain/ and docs/
Persistence
Direct read/write of real vault Markdown frontmatter -- no separate DB
Claude integration
Backend proxy holds the API key; browser never sees it
First-pass scope
Vertical slice on SOP only (simplest schema, lowest risk)
Asset handling
Extract + attach -- Claude pulls text/findings from uploaded files, source stays attached as evidence

Source prototypes evaluated

  • eqms_cognitive_compiler_dashboard.tsx -- free-text-to-structured-record compiler. Reused pattern: extraction into frontmatter, required-field validation.
  • eqms_engine_registry_sandbox.tsx -- lab EQMS console demo. Closest of the 3 to a real dashboard. Reused pattern: schema-as-data blueprints, status-lifecycle cards, audit log panel.
  • gemini_multimodal_workspace_compiler.tsx -- unrelated Google-Workspace ingestion product pitch. Reused pattern: asset-intake UI (repointed at QA documents/evidence), markdown-block renderer. Gemini API swapped for Claude.

Positive consequences

  • Frontmatter stays authoritative, no drift
  • No client-exposed API key
  • Low-risk validation slice before full build
  • Evidence files kept alongside Claude-assisted drafts

Negative consequences

  • No prototype proved real vault file I/O -- net-new code
  • New backend proxy is new operational surface
  • Two dashboard systems coexist during the transition (old Dataview for 5 record types, new app for SOP)
  • No charting library available in any source -- trend/effectiveness visualizations need to be built or sourced separately

Open / not yet decided

  • Backend framework/hosting for the Claude proxy
  • File-watching/write strategy against qa-brain/SOP/*.md
  • Whether/how _dashboards/Home.md links to the new app during the transition period
